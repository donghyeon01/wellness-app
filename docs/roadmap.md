### AI DEV OS 실행 순서

1. **프로젝트 기반 구조 + 인증**: client/server 디렉토리, Prisma schema, 인증 전체
2. **TODO + 캘린더**: 일정정리, 캘린더 이벤트 CRUD
3. **메모 + 일기**: 마크다운 메모, 감정 일기
4. **뽀모도로 + 대시보드**: 타이머, 세션 기록, 통합 대시보드
5. **테마 + 통합 검증**: 다크/라이트, 전체 빌드, 테스트
