## 리뷰 요약

T11 다크/라이트/시스템 테마 구현을 검토했다. 클라이언트 측 요구사항은 diff에서 직접 확인된다:

- `stores/theme.ts`: Zustand 스토어 + `localStorage('wellness-theme')` 동기화, 잘못된 값 폴백 처리 완료
- `ThemeProvider.tsx`: `darkMode: 'class'`에 맞춰 html/body에 클래스 적용, `system` 모드는 `matchMedia` 구독으로 OS 변경 실시간 반영, jsdom 폴백 포함
- `Header.tsx`: light→dark→system 순환 토글, 접근성 라벨/타이틀 포함
- 서버↔로컬 양방향 동기화(`ThemeSync`)는 dirty 플래그로 사용자 변경 보호, `prevTheme` 갱신으로 서버 값 재저장 루프도 차단됨

서버 측 `routes/settings.ts`/`services/settings.ts`는 diff가 잘려 직접 확인하지 못했으나, executor 요약(이전 실행에서 구현)과 `useSettings`/`useUpdateSettings` 훅 + 서버 테스트 30개 통과로 충족된 것으로 판단한다.

테스트 커버리지는 충분하다: ThemeProvider 8개(OS 변경 추적·폴백·클래스 적용), theme store 7개(localStorage 유지·유효성), Header 토글 순환 4개. "새로고침 후 테마 유지"도 `getInitialTheme` 테스트로 검증된다.

비차단 사항: `client/package.json`에 `zod`가 선언되지 않았다(현재는 워크스페이스 호이스팅으로 해결되나 명시 선언 권장). `client/src/index.html`은 vite가 사용하지 않는 중복 파일이다. 테마 클래스가 `useEffect`에서 적용되어 초기 페인트 시 FOUC 가능성이 있다(index.html 인라인 스크립트 권장).
